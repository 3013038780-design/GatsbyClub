# GatsbyClub 高端线下社群对标网站

当前网址：https://gatsbyclub-research.easy-tern-3117.chatgpt.site

Sites私有站点，仅所有者可访问。2026年10月24日发布。

## 阅读结构

1. 市场调研：商业、婚恋、旅行的付费需求与研究判断。
2. 对标：Founder Feast、BoL Selected、Other Way Round，逐一展开客户、收费、服务、流程、选择理由与不应照搬之处。
3. BoL整体会籍结构，以及钻石、奇语、The Offline Club的补充用途。
4. PDF、Excel、口语稿与来源。

官网截图、Founder Feast活动照片元素截图及用户提供的BoL原始页面用于研究讨论，版权归原机构。来源见`assets-sources.json`；不表示合作或背书。

本地预览：`python3 -m http.server 8787 --directory dist`。HTML/CSS/JS无需安装前端依赖。`build.py`复用同项目的报告与截图，需要原项目目录；`capture.mjs`和`photos.mjs`记录官网截图操作。浏览器核验脚本使用原环境Playwright路径，移机时需要调整。托管身份配置与临时凭据不进入GitHub归档。

已验证桌面1440×1000及手机390×844、三类对标切换、目录、图片对话框与Esc关闭、经营资料展开、3个成品下载、图片与锚点，无JS错误。QA截图及记录位于`qa/`。
