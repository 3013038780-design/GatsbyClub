# 北京有房/高净值局相亲活动｜MeetKnow线下见面局
**【活动时间】** 10月25日（周日） 15:00—17:00
**【活动地点】** 北京朝阳区。场地可能调整，具体地址以对应场次参与通知为准。
**【面向人群】** 有房或高净值人群；男士 30-46 岁 / 女士 24-40 岁；需完成实名与人脸核验，并提交相应证明
**【活动形式】** 主持人带领小范围面对面交流，包括一对一轮换及自由交流，具体安排以当场说明为准。
**【活动费用与规模】** 299元／场，最近一期限20人，以对应场次报名信息为准。
**【报名方式】** 通过MeetKnow小程序报名，按专场要求完成实名、人脸核验及所需资料审核。
## 一、活动特点与参与建议
经济与居住条件只是认识一个人的一部分，进一步交流时可以了解生活方式、消费观念及家庭规划，私密信息由双方自愿逐步沟通。
参加前核对专场条件和参与通知，建议提前10—15分钟到场。资料条件用于初步筛选，进一步认识仍需通过真实交流。
## 二、活动流程  
| 参考时间  | 环节  | 内容  |  
| --- | --- | --- |  
| 14:45—15:00  | 签到入场  | 现场核验身份与报名信息，领取席位。  |  
| 15:00—15:15  | 规则介绍与破冰  | 主持人介绍活动规则，带领破冰。  |  
| 15:15—16:15  | 一对一轮换交流  | 按轮次与每位嘉宾单独交流，避免全程只和一两个人聊。  |  
| 16:15—16:45  | 自由交流  | 自由选择感兴趣的对象继续深入沟通。  |  
| 16:45—17:00  | 填写心意选择  | 填写互选卡，活动结束后按双方互选结果交换联系方式。  |  
以上为常用流程参考，实际安排以对应场次说明为准。
