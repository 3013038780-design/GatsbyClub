# 商业板块宣导材料准备备忘录

日期：2026年11月9日  
致：商业内容团队  
用途：供双方确认文案任务与交稿安排，纳入平台统一宣导PPT  
状态：协作建议稿，交稿时间与具体人员待双方确认

## 一 本次需要大家共同完成什么

我们正在准备面向潜在渠道和城市合作人的平台宣导材料，希望将商业学习与生活方式两部分放在同一套介绍中。本次请商业团队先提供商业板块的介绍文字、产品思路和可使用案例，由总策划与运营统一整合成PPT。

这轮材料要让听众听明白：适合推荐什么人、这些人为什么愿意参加、参加后能获得什么，以及近期能先办什么。先把这四个问题讲具体，再共同确定会籍、收费与合作条件。

## 二 商业部分在整套介绍中的位置

整体介绍建议按“平台做什么 → 服务哪些人 → 商业与生活方式分别提供什么 → 怎样参加 → 渠道如何合作”展开。

商业板块重点呈现产业认知、企业经营和投资方法学习，以及线上内容、线下沙龙和企业参访的连续体验。AI与传统产业结合是重点主题之一，具体内容不限于AI。生活方式部分由生活方式团队提供，商业团队无需重复编写婚恋、旅游、健康和运动产品。

商业与生活方式活动倾向分场举办，参加者可按需求选择。是否统一会籍、分别购买或组合购买，另行共同确定。

## 三 请商业团队提供的六部分内容

### 1 服务哪些人

请分别写清以下客户的实际需要：

- 准备接班或已进入企业经营的年轻一代：处在什么岗位，最需要补哪些认知、经验和行业资源。
- 参与家族投资管理的年轻一代：希望理解哪些产业、投资方法和判断问题。
- 企业经营者与高管：为什么需要参加，对什么主题和交流对象感兴趣。

优先用日常接触到的真实问题说明。年龄、职业、职责和背景有依据就补充；还没有的信息留待沟通，不必为了凑齐画像填写统一收入或资产门槛。客户例子请匿名。

### 2 我们具体能够提供什么价值

请从可实际组织的内容出发，说明怎样帮助客户理解行业、讨论经营与投资问题、接触产业上下游及合适的专业人才。每个价值点尽量配一个活动或案例，而不只写“赋能”“资源丰富”。

涉及资源对接时，请说明我们能安排的是分享、交流、参访还是进一步协助；合作、招聘、融资或投资结果不作为既定交付。

### 3 产品怎样组织

请用一至两个主题，示范完整参与路径：

**线上课程或访谈了解主题 → 线下沙龙与行业人士讨论 → 实地参访理解企业 → 后续系列学习与交流。**

每一步请写：适合谁、讨论什么、用什么形式、需要多长时间、由什么角色交付、参加者能带走什么。会议中的AI漫剧可以作为示范主题，也可换成团队更有资源、更能近期落地的主题。

### 4 有哪些案例和资源可以支持

请提供已有的课程、沙龙、论坛或参访案例。每个案例说明主题、举办时间、团队承担的工作、参加者类型，以及可用于介绍的照片或反馈。

讲者、企业和合作机构按三种状态注明：已确认可参与、可以进一步协调、目前只有线索。公开使用的名称、个人介绍、照片与标识，请说明是否已获使用同意；尚未获得时先在内部参考，不放入对外成品。

### 5 近期最适合先办什么

请优先提出一场可落地的商业活动，另附一个备选。每场请填写：

| 项目 | 请填写内容 |
| --- | --- |
| 活动主题 | 听众能直接理解的题目与核心问题 |
| 适合客户 | 具体岗位、阶段、需求与必要条件 |
| 活动内容 | 分享、讨论、问答或参访的主要安排 |
| 交付资源 | 讲者角色、可协调企业及确认状态 |
| 举办条件 | 城市、场地设备、时长及建议人数 |
| 准备与费用 | 所需准备时间、讲者与内容成本线索、需要运营配合的事项 |

初期20—30人是会中提出的规模设想，可根据主题和场地调整。实际日期、人数、票价与成团条件待双方确认。

### 6 怎样持续服务与收费

请从交付角度提出建议：哪些内容适合按次参加，哪些适合持续学习；年度或阶段服务能提供什么，参访及游学是否需要单独收费，以及内容供给和人员成本有哪些限制。

本轮先提供收费结构与成本依据，不要求商业团队直接确定整个平台的售价、城市合作人政策或分成比例。既有档位和本次新提案中的差异，由双方另行定案。

## 四 首轮怎样交稿

建议先提供约6—8页PPT对应的文字提纲，无需先做完整设计。每页包括一个清楚的标题、主要说明及配图建议；已有照片和案例单独附上。暂缺内容请直接注明缺什么、由谁补，不影响先交齐结构。

可按以下顺序组织：商业板块介绍、客户需求、核心价值、产品路径、代表案例与资源、首场活动、持续服务建议。页数可随内容合并。

另外请附一张简短资源清单，记录“资源类型、可提供内容、确认状态、准备时间、费用线索及公开授权情况”。私人联系方式留在内部对接，不进入宣导成品。

## 五 双方怎样分工

| 工作 | 牵头与配合 |
| --- | --- |
| 确定整体框架与商业部分要求 | 总策划牵头，运营整理本备忘录并汇总问题 |
| 指定执笔与专业审阅 | 商业负责人安排；具体执笔和审阅人员待确认 |
| 提供商业内容、案例及资源状态 | 商业内容团队 |
| 提供生活方式内容与活动运营条件 | 生活方式与运营团队 |
| 整合PPT并核对表达 | 运营整合，双方审核各自内容，总策划统一口径 |
| 确定价格、权益、合作及收款规则 | 双方负责人共同决定，另行形成规则文件 |

## 六 本轮交稿前需要确认的安排

请双方确认：商业执笔与审阅人、首轮提纲交稿日期、整合稿反馈日期，以及渠道见面会的实际举办时间。会议提出“两周内启动”，需先明确起算日，再倒排文案、审核和活动准备。

首轮完成标准是：客户和价值讲得具体，产品路径能理解，至少有一场近期活动建议，案例和资源状态清楚。确认内容后，再完成视觉排版和对外发布审核。

投资公司及相关资产服务是会上提出的后端发展设想，是否写入宣导材料由双方负责人另行确认；本轮商业文案先以学习、交流与参访的实际交付为主。
