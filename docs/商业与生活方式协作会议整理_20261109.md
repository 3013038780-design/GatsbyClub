# 商业与生活方式协作会议整理

整理于2026年11月9日。会议实际日期未在所附转写中注明，暂不将整理日当作开会日。公开版按工作角色归纳；原始转写和个人资料留本机。

## 本次会议最重要的结果

统一宣导材料需要同时呈现商业与生活方式两块。近期先完成商业板块文字、候选场地核查及商业模式重构，再开展渠道见面会。会上提出“两周内启动”，起算日与实际日期待确认。

商业学习与交流继续作为主要方向。婚恋是触达客户的一种方式；生活方式涵盖婚恋、旅行、健康和运动等。两板块可以服务同一平台，但客户重叠程度、统一会籍还是分别购买尚未验证。此前“独立子品牌”保留为品牌方案，不能据此宣称已经决定分开收费或全部打包。

## 商业客户与产品比上一轮更具体

商业内容团队当前可触达的核心群体，是上市及非上市企业接班人、董事长与高管家庭；企业经营者和高管也可能参加。这是团队对现有资源的说明，不是已报名会员数量。未提供统一年龄、收入、资产或性格爱好分布。

接班人有两条不同需要：一类进入企业经营，希望理解行业、业务和管理；另一类参与家族投资，希望系统理解投资方法和产业。两类不宜只用“二代”一个标签写完。科技创业者与专业人士继续作为内容或产业连接方向，但不能把商业团队客群直接改写成AI创业者为主。

商业产品提出了连续路径（23:24—26:48）：

**线上课程或访谈了解主题 → 线下沙龙与行业人士讨论 → 实地参访理解企业 → 系列学习与持续交流。**

AI漫剧为会中举例，可用来示范这条路径，尚未确认为首讲或在售课程。产业认知、经营与投资方法为内容方向；具体讲者、机构和企业接待需逐项确认。

生活方式目前重点讨论婚恋社交、晚宴、高端旅行、运动与品牌合作。医疗健康、留学及移民等是延伸设想，尚未形成已核实的供应与价格。旅行每年3—5次也是规划建议。

## 宣导会与正式活动分清楚

宣导会主要向潜在渠道及城市合作人说明平台、产品和合作方式；正式商业/生活方式活动面向参加者交付体验，会上明确提出按场收门票、区分会员和非会员价格，并可在活动后介绍会籍。两类工作可以并行。

商业与生活方式活动倾向分场、轮动安排，不要求每场同时满足两种需求（30:51）。是否同一会籍、跨板块权益和付费如何衔接仍待决定。

## 商业团队文案收集提纲

建议按以下六部分交稿：1 服务谁及两类接班人的需要；2 能解决的具体问题；3 线上—沙龙—参访—持续学习的产品路径；4 可确认讲者/企业/过往活动；5 与生活方式怎样分别报名、如何自愿衔接；6 近期可落地的一场活动。材料区分已有照片/真实案例、可协调资源与未来设想，附使用授权情况。
