# 学习型高端社群定位更新

更新日期：2026年11月6日。依据：用户对11月1日会议的新方向说明及本轮进度确认。当前定义以[项目基础文件](项目定位与业务共识.md)为准。

## 一句话说清楚

用商学院式学习和AI产业交流，把有产业经验与经营问题的人，和懂AI技术、产品与商业落地的人聚在一起。主平台持续经营学习与信任，婚恋和高端旅游各做独立子品牌。

## 客户筛选先看什么

产业端先问：经营什么业务，当前最想解决什么问题，能否提供真实场景和讨论经验。技术端先问：做什么产品或技术，已有怎样的落地经历，想了解什么行业。两端都要问：愿意学什么、分享什么、多久参加一次、为怎样的具体服务付费。

年龄、收入、性格与爱好仍需访谈补充，不按“老钱”“新钱”两个词替代精准画像。主平台的参与资格与婚恋场次的单身/关系审核分别制定。
