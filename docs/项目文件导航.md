## 看到这些文件夹时，怎么判断

| 文件夹 | 内容 | 普通阅读是否需要 |
| --- | --- | --- |
| `交付文件/`、`deliverables/` | 报告、工作簿等阅读成品 | 优先看导航指定的当前版本 |
| `raw/`、`research/`、`social-platforms/`、`collection-*/` | 公开采集与研究过程 | 核查某个事实时再查 |
| `qa/`、`formatting/`、`qa_final/` | 排版截图、检查记录及中间渲染 | 日常不用逐一阅读 |
| `site/dist/`、`dist/` | 网页与随网页打包的下载文件 | 是展示副本，不单独决定最新版 |
| `历史版本/`、`旧版明细存档/` | 旧报告与旧数据 | 追溯当时决策时使用 |
