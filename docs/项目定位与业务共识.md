>

本文件记录项目当前做什么、服务谁、产品与收费框架，以及哪些事项尚未确定。它是持续更新的工作依据，不是完整商业计划书或已经签署的会员、合作、投资协议。

**状态说明**：**已确认方向**表示后续工作应遵循；**当前价格框架**表示可用于方案讨论，不表示全部权益已经定稿或已经对外销售；**待定**表示需要补充决定，不能自动填成既定承诺。

## 1. 我们在做什么

**已确认方向：以交友和共同体验为主的线下会员社群。**围绕同一批客户，持续组织有趣、有筛选、有交流价值的活动。单身、恋爱中、有伴侣及已婚客户，都可以参加适合其目的的产品。

商业交流、婚恋、旅行是三类需求，不是必须拆开的三家公司。婚恋是专门服务之一，不把整个品牌定位为婚介公司；旅行是深入相处的场景，也不是全部业务。

我们希望客户第一次因为同行者、主题或体验而来，参加后愿意再次见面，并逐步形成持续参与、推荐朋友及购买相应会籍的关系。总体商业方向是建立会员体系；具体会籍权益和收益机制仍在完善。

**品牌体验方向：有趣、鲜活、相处舒服。**除了人群条件，还要认真设计主题、互动、现场节奏和自由交流，避免活动只有头衔介绍或推销。

## 2. 服务谁

### 2.1 总体客户范围

采用以下五类人群作为招募与审核框架；符合其中一类、审核通过后，可参加适合自己的活动，不要求每个人同时满足五类。

| 人群方向 | 当前理解 | 待补标准 |
| --- | --- | --- |
| 高学历 | 有相应教育经历与交流基础 | 学历、院校或替代条件及证明方式 |
| 高背景 | 有明确专业身份、职业价值或社会贡献 | 适用职业、资历及可核材料；不把关系身份直接等同准入 |
| 高颜值 | 外在形象及整体气质 | 与具体活动相关的审核方式 |
| 高资产 | 有相应收入、资产与消费能力 | 个人/家庭、收入/资产口径及证明方式 |
| 高能量 | 有专业影响力、内容贡献、组织能力或优质资源 | 可观察的实际贡献与审核依据 |

目前没有全体会员统一的年龄、性别、住房、收入或资产硬门槛。此前讨论的年收入50万元、男性100万元等属于画像建议；不能自动写成全部客户的现行准入条件。

高资产仍是重要客群，但**不再把所有客户一律等同A8及以上**。5000万元、亿元验资可以设计为特定场次；具体条件以对应产品确认结果为准。

### 2.2 三种参与角色

- **付费体验者**：希望交友、拓展生活圈、学习交流或参加高质量活动。
- **核心嘉宾与资源贡献者**：为活动提供专业内容、主题资源、影响力或现场支持；是否赠送权益，按具体贡献另定。
- **资源或城市合作人**：愿意引荐合适客户、链接资源或参与执行；其收益与责任另列，不与普通消费会员混为一谈。

不同角色可以重合。当前没有证据支持已经形成统一的真实客户年龄、职业、收入、性格和爱好分布，后续应结合双方私域、渠道和真实参与反馈完善。

### 2.3 按活动说明关系目的

普通交友、商业交流、运动及生活方式活动可服务不同关系状态。婚恋专场需另行明确单身、恋爱意愿及双方适配条件；伴侣主题旅行服务恋爱或已婚伴侣。不能让客户报名后才发现活动目的与预期不同。

## 3. 产品框架

| 产品方向 | 想交付的体验 | 当前状态 |
| --- | --- | --- |
| 主题晚宴、下午茶 | 围绕共同话题认识人、交流及体验项目 | 已确认方向；首发主题、人数、票价和排期待定 |
| 婚恋交友活动 | 经审核的单身者，通过互动、交流和自愿联系认识彼此 | 已确认方向；筛选、主持、流程及匹配服务边界待定 |
| 运动与兴趣活动 | 高尔夫、网球等共同体验，兼顾认识与学习 | 已确认方向；教练、场地、器材和费用待定 |
| 讲座与分享 | 金融、心理、生活方式等具体主题，分享与交流结合 | 已确认方向；分享者及内容待定 |
| 稀缺活动推荐 | 对接普通报名较难取得的合适活动或名额 | 产品方向；资源、可用名额及合作方式待核实 |
| 特色沉浸活动 | 蒙面舞会、角色任务等有趣的共同体验 | 创意阶段；脚本、人员、场地与成本待设计 |
| 旅行、游学及企业参访 | 多日同行、主题体验、学习或参访 | 已确认方向；线路、承办方、标准与价格待定 |
| 伴侣关系主题旅行 | 通过共同经历和适当引导促进伴侣交流 | 新产品构想；导师、流程、边界与成本待定 |

“晚宴/旅行”是形式，“商业/婚恋/共同兴趣”是目的，后续产品卡应同时写清两者。不是所有活动都带相亲任务，也不是每场都需要同一套审核门槛。

主理人掌握品牌表达、现场主场与客户关系；主持、专业导师和气氛协作人员按实际产品配合。资源提及和合作设想不等于已确认供应，不把稀缺体验、名人或机构写成现有保证权益。

**名额规则待定**：名额对应什么会籍、受邀者是否仍须审核、使用期限、是否可转让、谁收款、是否含全部权益、退款和退出如何处理。不能仅凭“3个/6个名额”推导现金返还、可转售收入或保证回本。

**共同收费方向**：旅行单独收费，不自动包含在年费内。其他活动是否免费、成本收费或享会员价，按最终权益表确定。“会员旅行成本价”、全年15或20场活动、赠几场等尚未形成完整承诺。

会议中的5,000元活动价、4,000元会员价及其他举例金额不是已确定的具体活动报价。历史模型中的1,680/680/19,800元属于对应产品的研究试价，尤其“19,800元旅行试价”与本表“19,800元理事档”是不同用途，不可混用。

## 7. 启动方式与分工

- **启动城市**：北京先做，先用一个公司运作；跨城和多个主体以后再评估。
- **初期客户**：先梳理双方私域与渠道可触达的人，再核实真实需求。三个月约20名付费核心成员是阶段目标，不是已成交；不假定20人均属同档会籍。
- **前台与后台分工**：资源与品牌主理人侧重外部链接、嘉宾、渠道和产品创意；运营合伙人侧重主持、销售、落地、服务与团队。双方共同投入客户、资源和规划。
- **辅助团队**：先按需配线上内容、会员服务、摄影剪辑等兼职，实际费用与人选待核实，不急于固定全职团队。
- **触达**：私域与渠道先行，结合公众号、小红书、抖音、视频号；小型下午茶用于介绍项目及了解客户。微信社群形式待定，暂不急开发小程序。
- **场地**：先核实可合作场地及预约会议空间；环境、包间、展示与可用时间需实地确认，暂不把关联场地当作已确定免费资源。
