# 项目定位与业务共识

> 项目基础文件｜当前版本：2026年11月9日（纳入新一轮协作会议；实际会期待确认）
>
> 后续调研、产品设计、定价、模型、内容和网站工作，先阅读本文件，再阅读相关历史成果。

本文件记录项目当前做什么、服务谁、产品与收费框架，以及哪些事项尚未确定。它是持续更新的工作依据，不是完整商业计划书或已经签署的会员、合作、投资协议。

**状态说明**：**已确认方向**表示后续工作应遵循；**当前价格框架**表示可用于方案讨论，不表示全部权益已经定稿或已经对外销售；**待定**表示需要补充决定，不能自动填成既定承诺。

## 1. 我们在做什么

**已确认方向：以商学院式学习、主题讲座和交流作为前端的高端社群聚合平台，重点围绕AI与传统行业结合。**通过持续的线下学习和共同讨论，把有产业经验、业务与资源的人，以及有AI技术、产品与创业能力的人聚在一起，形成向上、互相赋能的长期关系。

“商学院式学习”指课程、案例讨论、讲座、参访等组织方式。现阶段没有确认院校合作、学历项目、证书或正式课程体系；对外名称与表述另行确定。

**11月9日协作更新**：平台按商业与生活方式两板块准备统一宣导材料，商业学习包括产业认知、经营及投资方法，不局限于AI。商业团队重点可触达企业接班人、董事长及高管家庭；具体产品采取线上内容、线下沙龙和实地参访相衔接的思路。商业和生活活动倾向分场轮动，会籍统一、分开或组合购买仍待重构。详见[会议整理与冲突清单](商业与生活方式协作会议整理_20261109.md)。

**品牌与业务关系（此前方向，收费与组织关系仍待确认）**：主平台先建立学习、交流与信任；婚恋和高端旅游作为子品牌独立运营，分别配置负责人、客群条件、产品与收费。成熟后可以相互导流，会员按意愿参加。主平台仍持续服务同一批客户，不把每个人都导向相亲或旅行。

**核心连接方向**：传统产业经营者与科技创业、AI产品及技术人才。会议所说“老钱与新钱融合”在工作中落为两端的真实需求匹配：产业方有什么经营问题和应用场景，技术方有什么可交付方案，双方为什么愿意反复交流。具体合作成果需通过实际活动验证。

**品牌体验方向：向上、互相赋能，同时有趣、鲜活、相处舒服。**学习内容要有具体业务问题与交流机会，活动避免只有头衔介绍或推销。

## 2. 服务谁

### 2.1 总体客户范围

本次商业团队重点服务两类企业接班人：进入企业经营者，以及参与家族投资管理者；并覆盖企业经营者与高管。相应需要分别是产业/经营认知与投资方法学习。该客群为团队自述的现有触达方向，不是已成交画像；科技创业者与专业人士仍可参与产业连接与内容贡献。

原有主平台客户方向继续保留：下表是本轮招募与访谈方向，年龄、收入和资产门槛尚未确定。

| 优先客群 | 具体是谁 | 希望从平台获得什么 |
| --- | --- | --- |
| 传统产业经营者与接班人 | 管理真实企业、掌握业务流程或应用场景，想理解AI如何影响经营的人 | 看懂应用、讨论转型问题、认识可合作的技术与产品人才 |
| 科技与AI创业、产品和技术负责人 | 有相关项目、技术或产品经验，希望理解产业需求与商业落地的人 | 接触真实场景、交流商业化问题、建立产业与合作关系 |
| 专业人士与内容贡献者 | 能讲清AI、经营管理或行业案例，愿意参加持续讨论的人 | 交流专业经验、参与学习与共创、形成长期同行关系 |

婚恋子品牌另行确认单身状态、关系意愿与适配条件；旅游子品牌按主题、预算、时间和同行期待筛选。不能把消费能力相同当作学习需求或关系需求相同。

**原有“五高”框架继续作为辅助观察维度，不代替主平台的学习需求、实际贡献和交流适配。**

保留以下五类人群作为不同产品的招募参考，不要求每个人同时满足五类。主平台是否适合参加，还要结合学习需求、行业经验和交流贡献判断。

| 人群方向 | 当前理解 | 待补标准 |
| --- | --- | --- |
| 高学历 | 有相应教育经历与交流基础 | 学历、院校或替代条件及证明方式 |
| 高背景 | 有明确专业身份、职业价值或社会贡献 | 适用职业、资历及可核材料；不把关系身份直接等同准入 |
| 高颜值 | 外在形象及整体气质 | 与具体活动相关的审核方式 |
| 高资产 | 有相应收入、资产与消费能力 | 个人/家庭、收入/资产口径及证明方式 |
| 高能量 | 有专业影响力、内容贡献、组织能力或优质资源 | 可观察的实际贡献与审核依据 |

目前没有全体会员统一的年龄、性别、住房、收入或资产硬门槛。此前讨论的年收入50万元、男性100万元等属于画像建议；不能自动写成全部客户的现行准入条件。

高资产仍是重要客群，但**不再把所有客户一律等同A8及以上**。5000万元、亿元验资可以设计为特定场次；具体条件以对应产品确认结果为准。

### 2.2 三种参与角色

- **付费体验者**：希望交友、拓展生活圈、学习交流或参加高质量活动。
- **核心嘉宾与资源贡献者**：为活动提供专业内容、主题资源、影响力或现场支持；是否赠送权益，按具体贡献另定。
- **资源或城市合作人**：愿意引荐合适客户、链接资源或参与执行；其收益与责任另列，不与普通消费会员混为一谈。

不同角色可以重合。当前没有证据支持已经形成统一的真实客户年龄、职业、收入、性格和爱好分布，后续应结合双方私域、渠道和真实参与反馈完善。

### 2.3 按活动说明关系目的

普通交友、商业交流、运动及生活方式活动可服务不同关系状态。婚恋专场需另行明确单身、恋爱意愿及双方适配条件；伴侣主题旅行服务恋爱或已婚伴侣。不能让客户报名后才发现活动目的与预期不同。

主理人掌握品牌表达、现场主场与客户关系；主持、专业导师和气氛协作人员按实际产品配合。资源提及和合作设想不等于已确认供应，不把稀缺体验、名人或机构写成现有保证权益。

## 7. 启动方式与分工

- **城市布局**：本次拟北京与深圳分别作为南北核心推进。两城具体人力、预算、顺序待核；不据此视为同时开业或已有完整双城交付团队。主体安排没有新决定。
- **初期客户**：先梳理双方私域与渠道可触达的人，再核实真实需求。三个月约20名付费核心成员是阶段目标，不是已成交；不假定20人均属同档会籍。
- **前台与后台分工**：资源与品牌主理人侧重外部链接、嘉宾、渠道和产品创意；运营合伙人侧重主持、销售、落地、服务与团队。双方共同投入客户、资源和规划。
- **辅助团队**：先按需配线上内容、会员服务、摄影剪辑等兼职，实际费用与人选待核实，不急于固定全职团队。
- **本次工作优先级**：先给商业团队文案提纲并收集商业内容，核对两城候选场地，再完成收费/合作规则和渠道见面会准备。宣导与正式售票活动可并行设计；前者面向渠道/合作人，后者交付商业或生活体验。
- **触达与首场（上一轮设想，服从本次优先级）**：私域与渠道先行，结合公众号、小红书、抖音、视频号。优先筹备社群宣导与学习需求沟通，之后安排有明确主题的AI与商业讲座。10月30日交友下午茶为旧方向初案，是否使用其形式需按新目标重审。微信社群形式待定，暂不急开发小程序。
- **场地**：先核实可合作场地及预约会议空间；环境、包间、展示与可用时间需实地确认，暂不把关联场地当作已确定免费资源。
