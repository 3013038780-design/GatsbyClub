# 归档与验收

本目录用于同步追溯、核验和工具来源，不放当前产品定义。日常先看[项目基础文件](../docs/项目定位与业务共识.md)和[最新成果](../README.md#最新成果)。

| 文件 | 作用 |
| --- | --- |
| [文件清单](文件清单.jsonl) | 逐文件大小与SHA-256，不包含清单自身 |
| [归档范围](归档范围.json) | 收录范围与排除类别 |
| [研究验收](20261024计划验收审计.json) | 研究交付与外部待补的区别 |
| [基础文件核验](20261027基础文件核验.json) | 业务共识、价格与首读入口 |
| [文件整理核验](20261027文件整理核验.json) | 本轮分类、导航、链接与原成品保持情况 |
| [工具来源](工具来源.md) | 工具和本地改动 |

文件名中的日期对应当轮工作；新的更新见[CHANGELOG](../CHANGELOG.md)。历史同步记录不替代当前文件清单。原始公开证据分布在各研究目录及资料包中，不把私人账号和内部股权资料混入归档。
